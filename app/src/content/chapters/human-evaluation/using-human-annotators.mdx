#### 使用人类标注者

我建议读一读这篇关于数据标注质量良好实践的[综述](https://aclanthology.org/2024.cl-3.1/)的第 3 节。如果你想要生产级质量，并且有条件实施所有这些方法，那就放手去做！

<HtmlEmbed src="d3-quality-management.html" frameless />

不过，无论你的项目规模大小，一旦你定义好任务和评分指南，以下这些重要准则都适用。

- **人员筛选，以及（如果条件允许）金钱激励**
你很可能希望参与你任务的人：
1) 符合某些人口统计特征。 
	一些例子：是目标语言的母语者、受过更高水平的教育、是某个特定领域的专家、地理来源多样，等等。 
	 你的需求会因任务而异。
1) 产出高质量的工作。
	如今尤其重要的是，要加入一种检查答案是否由 LLM 生成的方法，并且你需要把某些标注者从你的池子里筛掉。
  *在我看来，除非你指望的是积极性极高的众包标注者，否则给标注者支付合适的报酬总是更好的做法。*

<Sidenote>

除非你拥有积极性极高的众包标注者，否则一定要支付公平的报酬。报酬过低的标注者产出的工作质量更低、引入更多错误，还可能用 LLM 快速完成任务。
</Sidenote>

- **指南设计**
一定要投入大量时间去真正地头脑风暴你的指南！在 [GAIA](https://huggingface.co/gaia-benchmark) 数据集上，这是我们投入时间最多的环节之一。

<Sidenote>

在创建 [GAIA 基准](https://huggingface.co/gaia-benchmark)时，指南设计比其他任何阶段都更耗时。清晰、无歧义的指南值得这份投入——它们能避免代价高昂的重新标注轮次。
</Sidenote>

- **迭代式标注** 
要做好进行多轮标注的准备，因为你的标注者会误解你的指南（它们比你想象的更含糊）！多次生成样本能让标注者真正收敛到你需要的标准上。

  - **质量估计**与**人工筛选**
你需要对答案进行把控（尤其是通过标注者间一致性——如果你能拿到的话），并做最终筛选，只保留质量最高/最相关的答案。

[Argilla](https://argilla.io/) 这类用于构建带标注的高质量数据集的专用工具也能帮到你。

<Note title="延伸阅读">
- ⭐ [如何在几分钟内搭建自己的标注平台](https://huggingface.co/learn/cookbook/enterprise_cookbook_argilla)，作者 Moritz Laurer。这是一篇好读物，能让你动手体验开源工具（如 Argilla 和 Hugging Face），并更好地理解大规模人工标注的该做与不该做。
- ⭐ [一份标注良好实践指南](https://aclanthology.org/2024.cl-3.1/)。它综述了 2023 年以来所有关于人工标注的论文，内容非常完整。略显密集，但很好懂。
- [另一份标注良好实践指南](https://scale.com/guides/data-labeling-annotation-guide)，来自 ScaleAI，专注于人工评测。它是对上述文档更轻量的补充。
- [捕获人类标签的假设与挑战](https://aclanthology.org/2024.naacl-long.126/) 是一篇论文，讲如何看待标注者分歧的来源并在实践中加以缓解
</Note>

<Accordion title="实用技巧与提示">
以下是使用人工标注者构建评测数据集时，你可能需要考虑的一些实用技巧。


**设计任务**

- **越简单越好**：标注任务很容易变得不必要地复杂，所以要尽可能保持简单。把标注者的认知负荷降到最低，有助于确保他们保持专注，并做出质量更高的标注。
- **检查你展示的内容**：只展示标注者完成任务所必需的信息，并确保不包含任何可能引入额外偏见的内容。
- **考虑标注者的时间**：内容的展示位置与展示方式可能带来额外的工作量或认知负荷，进而对结果质量产生负面影响。例如，确保文本与任务同时可见，避免不必要的滚动。如果你把多个任务组合起来，且一个任务的结果会影响另一个任务，可以将它们按顺序展示。思考标注工具中所有内容的呈现方式，看看是否还有进一步简化的空间。
- **测试整套设置**：任务设计完成、指南就位之后，务必先在少量样本上自己测试一遍，再让整个团队参与进来，并按需迭代。

**标注过程中**

- **标注者应独立工作**：最好让标注者在任务期间互不帮助、也看不到彼此的工作，因为他们可能传播自己的偏见，导致标注漂移。对齐应始终通过完整的指南来实现。你可能需要先在一个单独的数据集上培训新成员，和/或使用标注者间一致性指标来确保团队已经对齐。
- **一致性是关键**：如果你对指南做了重要修改（例如修改了某个定义或指令，或者增加/删除了标签），要考虑是否需要重新处理已标注的数据。至少，你应当通过类似 `guidelines-v1` 这样的元数据值来跟踪数据集中的变更。

**人机混合标注**

有时团队面临时间和资源上的限制，但又不想牺牲人工评测的优点。在这种情况下，你可以借助模型让任务更高效。

- **模型辅助标注**：你可以把模型的预测或生成结果用作预标注，这样标注团队就不必从零开始。只需注意，这可能会把模型的偏见引入人工标注；而且如果模型的准确率很差，反而可能增加标注者的工作量。
- **以模型为裁判并加以监督**：你可以把“模型作为裁判”方法的能力（见“模型作为裁判”一节）与人类监督者结合起来，由后者验证或丢弃结果。注意，“人工评测的优缺点”中讨论的偏见在这里同样适用。
- **识别边界情况**：想要更快的任务流程，可以使用一组模型组成的评审团，然后让人类监督者在模型出现分歧或打平时介入裁决。同样，要留意“人工评测的优缺点”中讨论的偏见。

</Accordion>
